Blog 界面样本

下面是三种不同方向的静态示意页，仅用于挑选整体气质与版式。确定方向后，可把偏好告诉我，再落到正式的 blog_yc.html / style_blog.css。

  • 综合示意 · 总览 A + 分类时间线（example） #all 全文时间线；#main-* 大类；#sub-* 子类时间线。尚未合并进正式 blog。
  • 样本 A · 杂志/编辑风 宽栏、衬线标题、留白多；适合长文气质与「出版物」感。
  • 样本 B · 卡片栅格 分类标签 + 卡片网格；信息密度清晰，适合文章多、需要扫读。
  • 样本 C · 时间线/阅读清单 窄栏、日期优先、竖线时间轴；偏日记/笔记流，结构一目了然。

本地预览：在项目根目录运行 python -m http.server，然后打开 /blog-samples/。
